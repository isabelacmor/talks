# Becoming a Code Review Champ

## Abstract

Reviewing PRs is something every engineer should be doing, regardless of how senior or junior you are or how new you are to a team or codebase. It's what keeps our codebases manageable and our code quality high... if we do it right.

Ultimately, we're responsible for every line of code that gets merged into our codebase. In this talk, we'll cover specific strategies to become the best code author and reviewer you can be and use PR reviews as a mentorship exercise in your teams.

Level: Beginner+

Length: 10-30 mins

## Description

### Objectives

- Provide actionable tips for becoming a responsible code author and pre-reviewing your own code.
- Provide actionable tips for reviewing others' code, including _what_ to look for and _how_ to do so effectively.
- Frame PR reviews as a mentorship and learning exercise within engineering teams.

This talk is beginner-friendly and provides actionable steps that can be tailored to engineers across all career levels.
